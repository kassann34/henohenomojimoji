# へのへのもじもじ — 漢字福笑い

漢字を一画ずつバラバラにして遊ぶ、福笑いのブラウザゲームです。
4字で1セット。できあがった自分の字をつなげて「存在しない四字熟語」を作ります。ひとりでも、オンラインで数人でも遊べます。

## 遊び方

初めて開いたときは、遊び方を4枚の絵で見せる案内が出ます（タイトル横の「？」でいつでも開き直せます）。

### ひとりで

1. お手本の漢字が3秒間表示されるので覚えます。
2. 半紙に目隠しがかかります。下の「おぜん」から画をドラッグして半紙に運びます。置いた画は見えなくなります。
3. 全部置いたら「目隠しをとる」。お手本とのシルエットの近さで採点され、判子が押されます（名人・達筆・まずまず・へのへの・もじもじ）。
4. これを4字くり返すと、自分の作った4字が縦長の半紙に並んだ「存在しない四字熟語」と合計点（400点満点）が出ます。

タイトル横のボタンで、背景を紺と白で切り替えられます（紺のときは、アイコンの「墨」の色が白になります）。

お題は約1000字（小学校で習う教育漢字のうち3画以上＋α）から完全にランダムに出ます。

### みんなで

1. **入室とアイコン作り**：「みんなで」タブで、好きな漢字1字と色を決めて「部屋を作る」（またはコードを入れて「入る」）。名前の入力はなく、アイコンがその人の目印になります。入室するとその字で福笑いのチュートリアルが始まり、できた字がそのまま自分のアイコンになります（選んだ色で表示）。ロビーで字や色を変えて作り直せます。
2. **ロビー**：参加者のアイコンと前回の点数が並びます。アイコンにカーソルを合わせる（スマホはタップ）と、その人の前回の四字熟語が見られます。招待リンクやコードはロビーに出ます。
3. **1字ずつ全員同時**：親（部屋を作った人）が「はじめる」と、全員に同じ字が同時に出ます。制限時間は1字60秒（お手本を見る3秒を含む）。時間切れになった人は、そのときの配置のまま採点されます（半紙に置いていない画は数えません）。
4. **1字ごとの結果**：全員がそろうか時間切れになると、約5秒間、全員の字と点数、合計点の推移グラフが出て、自動で次の字へ進みます。
5. **結果発表**：4字終わると、順位・推移グラフ・優勝者の四字熟語（大きく表示）・全員の四字熟語が出ます。親が「ロビーへ戻る」を押すとロビーに戻ります。
6. **漢字1字チャット**：部屋の中ではいつでも、上の入力欄から漢字1字を送れます。送った人のアイコンの上に、その人の色の吹き出しで出ます。

進行（時間切れの判定、次の字、結果発表）は親の画面が受け持ちます。親が抜けると、次に早く入った人が親を引き継ぎます。途中から入った人は、そのゲームは観戦になり、次のゲームから参加できます。

## 動かし方

ビルド不要の静的ページです。GitHub Pages（Settings → Pages → Branch: `main` / `/ (root)`）で公開できます。

「みんなで」を使うには、無料の Firebase Realtime Database の設定が一度だけ必要です（下記）。

## Firebase の設定（みんなで用）

1. <https://console.firebase.google.com/> で「プロジェクトを追加」（Google アナリティクスは不要）。
2. 左メニュー「構築 → Realtime Database」→「データベースを作成」。場所はシンガポール（asia-southeast1）など近いところ、モードは「ロックモード」で作成。
3. Realtime Database の「ルール」タブに、このリポジトリの `database.rules.json` の中身を貼り付けて「公開」。
4. プロジェクトの設定（歯車）→「マイアプリ」でウェブアプリ（`</>`）を追加し、表示された `firebaseConfig` の中身を `firebase-config.js` の `null` と置き換えて保存・プッシュ。

`apiKey` などはブラウザに公開される前提の値なので、リポジトリに入れて問題ありません。データへのアクセスは `database.rules.json` のルールで `rooms/` の下だけに制限しています。部屋コードを知っている人は誰でも参加・書き込みできる、パーティーゲーム向けのゆるい設定です。

### Firebase なしで動作確認する

URL の末尾に `?mock=1` を付けると、同じブラウザのタブ同士で部屋を共有する疑似サーバーで動きます（例: `index.html?mock=1` を2つのタブで開き、片方で部屋を作ってもう片方で入る）。
さらに `&fast=1` を付けると、制限時間が15秒・結果表示が3秒に短くなり、通しの確認がすぐできます。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面（HTML / CSS） |
| `app.js` | ゲームの処理（画の配置・採点・4字セット・ひとりで・みんなで） |
| `firebase-config.js` | Firebase の接続設定（各自で記入） |
| `database.rules.json` | Realtime Database のセキュリティルール |
| `kanji-data.js` | 漢字ごとの画データ（自動生成。部首ごとの区切りも入っているが、いまのゲームでは使っていない） |
| `tools/build_data.py` | KanjiVG の SVG から `kanji-data.js` を作るスクリプト |

### 漢字を増やす

```sh
# KanjiVG の kanji/ フォルダから必要な SVG（例: 0660e.svg）を取得しておく
# いま収録している字は tools/kanji-list.txt。増やすときはこのファイルに字を書き足して再生成する
python3 tools/build_data.py <KanjiVGのkanjiフォルダ> kanji-data.js "$(cat tools/kanji-list.txt)"
```

## 更新するとき

ブラウザや GitHub Pages が古い JavaScript を使い続けないよう、`index.html` の `<script src="app.js?v=…">` の `v=` の数字を、ファイルを更新するたびに新しい値（日付など）に変えてください。
